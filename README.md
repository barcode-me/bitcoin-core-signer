# Bitcoin Core BIP39 Signer

For dev resources go to [DEV.md](./DEV.md).

To read this guide you can: 

- access the GitHub Pages version https://barcode-me.github.io/bitcoin-core-signer/index.html
- download the release which already contains the static assets of the build https://github.com/barcode-me/bitcoin-core-signer/releases
- build it yourself, tou will need to install [Nodejs](https://nodejs.org/en/download) and run:

```bash
npm i
npm run build
open build/index.html
```

Simply open the index.html page and enjoy!
