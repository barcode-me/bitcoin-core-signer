# Bitcoin Core BIP39 Signer

For dev resources go to [DEV.md](./DEV.md).

To read this guide you can either download the release which already contains the static assets of the build or you can build it yourself very quickly. You will need to install [Nodejs](https://nodejs.org/en/download).

```bash
npm i
npm run build
open build/index.html
```

If you end up downloading the assets simply open the index.html page and enjoy!
